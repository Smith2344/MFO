# MFO — Simulator

🎮 **Играть онлайн:** [https://Smith2344.github.io/MFO/](https://Smith2344.github.io/MFO/)

## О проекте
Веб-симулятор **MFO** с поддержкой входа через Google и локализацией интерфейса.

## Возможности
- Авторизация и выход через Google-аккаунт
- Переключение языка в настройках (Украинский, English, Русский)
- Сохранение прогресса и настроек
